# 机会雷达 - 实时数据源配置指南

机会雷达现已支持**后端实时聚合**，可对接正式开放平台 API 获取真实招聘/兼职数据。

## 架构说明

- **前端**：优先请求 `/api/opportunities/search`，若返回 `fromRealAPI: true` 则展示实时数据
- **后端**：Vercel Serverless (`api/opportunities/search.js`) 或 Node 服务 (`server/server.js`)
- **数据源**：按优先级依次尝试 实习僧 → 聚合数据 → 58同城（需配置对应 Key）

## 一、实习僧开放平台（推荐）

**真实实习/兼职数据，需联系商务获取凭证。**

1. 访问 [实习僧开放平台](https://open.shixiseng.com/)
2. 联系商务获取 `APP_ID`、`APP_SECRET`
3. 配置 IP 白名单（Vercel 部署需添加 Vercel 的出口 IP 或使用动态 IP 方案）
4. 在 Vercel 项目设置中新增环境变量：
   - `SHIXISENG_APP_ID` = 你的 APP_ID
   - `SHIXISENG_APP_SECRET` = 你的 APP_SECRET

## 二、聚合数据 招聘信息大全

**多平台聚合，当前接口维护中。**

1. 注册 [聚合数据](https://www.juhe.cn/)
2. 申请「招聘信息大全」接口，完成实名认证
3. 购买套餐后获取 API Key
4. 环境变量：`JUHE_JOB_API_KEY` = 你的 Key

## 三、58同城开放平台

**需商务对接，获取 app_key / app_secret。**

1. 在 58 开放平台注册并提交资质
2. 创建应用，获取 app_key、app_secret
3. 环境变量：`API_58_APP_KEY`、`API_58_APP_SECRET`

## 四、本地/自建后端

若使用 `server/server.js` 本地或自建部署：

1. 复制 `server/env.example` 为 `server/.env`
2. 填入上述环境变量
3. 启动服务后，前端请求同域 `/api/opportunities/search` 即可

## 五、合规与限制

- **实习僧**：需商务授权，遵守其 API 使用协议
- **聚合数据**：付费接口，遵守数据使用条款
- **58同城**：需资质审核，禁止未授权爬虫
- **禁止**：对未提供开放 API 的站点进行爬虫抓取，以免违反 ToS 与法规

## 六、未配置时的行为

未配置任何 API Key 时，`/api/opportunities/search` 返回 `fromRealAPI: false`，前端自动降级为：
1. AI 生成（需 DeepSeek Key）
2. 本地兜底数据 + 真实平台搜索链接

用户仍可正常使用，仅数据非实时。
