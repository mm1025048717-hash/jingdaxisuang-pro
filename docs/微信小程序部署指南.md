# 精打细算 Pro · 微信小程序部署指南

## 一、方案说明

当前采用 **web-view 内嵌 H5** 方案：小程序只负责壳，实际内容加载你已部署的 Web 版（https://jingdaxisuang-pro.vercel.app/）。

**优点**：开发快、维护简单，Web 更新后小程序自动生效  
**限制**：需配置业务域名，且**仅企业主体**支持

---

## 二、前置条件

### 1. 主体类型

| 主体类型 | 是否可用 web-view 加载外部 H5 |
|----------|-------------------------------|
| **企业** | ✅ 可配置业务域名，支持 |
| **个人** | ❌ 不支持，需改原生或 uni-app |

### 2. 域名要求（企业主体）

- 使用 **HTTPS**
- 已做 **ICP 备案**（国内服务器）
- Vercel 的 `*.vercel.app` 无国内备案，**无法直接配置**

**可选做法**：
- **A**：将 Web 部署到**已备案的国内域名**（如阿里云、腾讯云），再配置业务域名
- **B**：使用腾讯云开发等提供备案域名的服务

---

## 三、部署步骤

### 步骤 1：注册小程序

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)
2. 选择「小程序」→ 立即注册
3. 填写邮箱、密码，选择主体类型（企业/个人）
4. 完成管理员扫码验证

### 步骤 2：获取 AppID

1. 登录 [小程序后台](https://mp.weixin.qq.com/)
2. 开发 → 开发管理 → 开发设置
3. 复制 **AppID**

### 步骤 3：配置项目

1. 打开 `miniprogram/project.config.json`
2. 将 `"appid": "请替换为你的AppID"` 改为你的 AppID

### 步骤 4：配置业务域名（企业主体）

1. 小程序后台 → 开发 → 开发管理 → 开发设置
2. 找到「业务域名」
3. 点击「开始配置」，添加你的 **已备案 HTTPS 域名**
4. 下载校验文件，放到域名根目录供微信验证

**若使用 Vercel 域名**：`vercel.app` 无国内备案，无法通过，需改用已备案域名。

### 步骤 5：本地开发与预览

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具
3. 导入项目：选择 `穷人军师/miniprogram` 目录
4. 填写 AppID（或使用测试号）
5. 开发阶段可在「详情 → 本地设置」中勾选「不校验合法域名」便于调试

### 步骤 6：上传与发布

1. 开发者工具 → 上传
2. 填写版本号、备注
3. 小程序后台 → 版本管理 → 选择版本提交审核
4. 审核通过后在「版本管理」中发布

## 四、个人主体可选方案

个人主体无法使用 web-view 加载外部 H5，可考虑：

### 方案 A：uni-app 转小程序

- 用 [uni-app](https://uniapp.dcloud.net.cn/) 将现有逻辑改写为跨端
- 一套代码可发 H5 + 微信小程序 + 其他端
- 需要一定开发量

### 方案 B：原生小程序重写

- 用微信小程序的 WXML/WXSS/JS 重写核心页面
- 工作量大，但体验最好

### 方案 C：申请企业主体

- 以个体户或公司身份重新注册小程序
- 满足条件后即可使用当前 web-view 方案

## 六、修改 H5 地址

如需更换内嵌页面地址，编辑 `miniprogram/pages/index/index.js`：

```js
data: {
  webUrl: 'https://你的域名.com/'
}
```

修改后需在「业务域名」中增加对应域名（企业主体）。
