## 一、项目概述

**精打细算 Pro（Poor Man's Advisor Pro）** —— 不只「度过危机」，更是**「从危机到致富的陪伴者」**。

聚焦「帮普通人管钱」这一垂直场景，随用户从钱紧→稳定→有积蓄的不同阶段，提供对应价值，延长用户生命周期。

### 核心能力

| 模块 | 功能 |
|------|------|
| **生存概览** | 生存天数、危险等级、日预算、距发薪、账单提醒 |
| **AI 军师** | 12 项技能：财务分析、机会搜索、记账、预算、债务话术、技能学习等 |
| **机会雷达** | 跨 30+ 平台聚合兼职/零工/变现/薅羊毛/打折，AI 扫描 + 技能匹配 |
| **数据可视化** | DataAgent 风格财务仪表盘 |
| **OpenClaw 联动** | 一键复制指令发给小龙虾执行 |
| **登录与云端** | 手机号/微信登录，数据跨设备同步 |

### 技术栈

- **前端**：HTML5 / CSS3 / JavaScript（PWA）
- **AI**：DeepSeek Function Calling
- **规则引擎**：本地 JavaScript，全离线兜底
- **部署**：Vercel 静态托管 / Node.js 可选后端

## 二、政策与市场背景

### 政策契合

- 总书记强调**「就业是最基本的民生」**，促进高质量充分就业；加强灵活就业和新就业形态劳动者权益保障
- 2024 年《就业优先战略》支持拓展数字经济就业新空间
- 我国灵活就业人员超 **2.4 亿**，新就业形态约 **6500 万**
- 精打细算聚合机会、缩短信息差、增强劳动者获得感，符合政策方向

### 市场空白

- **记账类**（随手记、鲨鱼记账）：以消费记录、预算为主，缺少生存导向、可执行清单
- **兼职平台**（58、BOSS、斗米）：信息分散，缺乏跨平台聚合与技能匹配
- **AI 理财**（蚂小财）：主打有持仓用户，对「钱紧」场景覆盖不足
- **精打细算差异化**：生存天数 + 可执行任务 + 债务话术 + 跨 30+ 平台机会聚合，全周期陪伴

### 目标用户

| 群体 | 规模 | 核心需求 |
|------|------|----------|
| 下沉市场 | 三线及以下 6.47 亿 | 性价比、实用工具、无需银行账户 |
| 大学生/年轻人 | 44.7% 有副业经验 | 收入、技能提升、防骗 |
| 日结/零工 | 超 1000 万骑手等 | 附近工作、秒到账、防黑中介 |
| 债务压力 | 花呗/借呗超 4 亿用户 | 延期、减免、协商话术 |

## 七、快速开始与部署

### 本地运行（带后端）

```bash
cd 穷人军师
npm start
```

浏览器访问 http://localhost:3000。手机上用：电脑开 `npm start`，手机同 WiFi 访问 `http://电脑IP:3000`。

### 仅前端

直接打开 `index.html`，数据存 localStorage。

### 部署到 GitHub

```bash
git add .
git commit -m "docs: 商业计划书 README 更新"
git push origin main
```

### 部署到 Vercel

1. 打开 [vercel.com](https://vercel.com)，点击 **Add New Project**
2. 选择 GitHub 仓库 `jingdaxisuang-pro`
3. 无需额外配置，直接 **Deploy**
4. 部署完成后访问 `https://xxx.vercel.app`

Vercel 部署为静态站点，数据使用 localStorage。如需云端同步，请本地运行 `server` 或自建后端。
